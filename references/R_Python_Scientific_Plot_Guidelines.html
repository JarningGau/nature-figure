R/Python Scientific Plot Guidelines

This guide is for an agent generating scientific plots using R or Python. All final figure files must be saved as PDF only.

1. Required Output Format

  • Save every final figure as PDF.
  • Do not save or return EPS, AI, PPT, PPTX, PNG, JPG, JPEG, TIFF, TIF, BMP, GIF, GIMP or Tex as the final figure.
  • Use vector PDF for graphs, charts, scatter plots, line plots, bar plots, boxplots, histograms and schematics.
  • Keep text editable/selectable in the PDF.
  • Do not convert text to outlines, curves or paths.
  • Do not add drop shadows, 3D effects, bevels, glows or decorative raster effects.
  • Exception: dense scatter plots may use an internally rasterized point layer, but the final delivered file must still be PDF.

2. Figure Size

Create the figure at its final publication width. Do not enlarge or shrink the figure after export.

Journal type 1-column width 2-column width
Nature Research Journals 88 mm 180 mm
All other journals 85 mm 175 mm

Convert millimetres to inches using:

inches = mm / 25.4
Width Inches
88 mm 3.4646 in
180 mm 7.0866 in
85 mm 3.3465 in
175 mm 6.8898 in

If the target journal is unknown, use 85 mm for a 1-column figure and 175 mm for a 2-column figure.

3. Text Rules

  • All text must use a sans-serif font.
  • Prefer Helvetica or Arial.
  • If Helvetica or Arial is unavailable, use another sans-serif font.
  • Maximum text size: 7 pt.
  • Minimum text size: 5 pt.
  • A practical default is 6 pt for labels and titles, and 5 pt for tick labels and legends.

Convert points to inches using:

inches = points / 72

In Python and R, font size arguments are normally interpreted as points, so manual conversion is usually not needed.

4. Colour Rules

  • Use RGB colour mode.
  • Do not export CMYK PDFs unless specifically requested.
  • Use clear, flat colours.
  • Avoid gradients unless scientifically necessary and readable at 5-7 pt text size.

5. Raster Image Rule

If a figure contains photographs, microscopy images, gel images, blot images or other raster data, the source raster image should be at least 300 dpi at the size used in the figure.

  • Do not artificially upscale low-resolution images.
  • Do not export the final figure as PNG, JPG or TIFF.
  • Embed the raster image into the plot and save the final figure as PDF.

6. Dense Scatter Plot Rule

For scatter plots with many points, avoid generating one vector object per dot. This can create very large PDF files and slow down rendering.

  • If a scatter plot contains more than 100 plotted points, consider rasterizing the point layer.
  • Do not create a separate vectorized element for each dot.
  • Rasterize only the point cloud, not the whole figure.
  • Keep axes, axis labels, tick labels, title, legend, annotations, trend lines, error bars, confidence bands and panel labels as vector objects whenever possible.
  • Use at least 300 dpi for the rasterized point layer.
  • The final file must still be PDF.
  • Do not output a separate PNG, JPG or TIFF as the final figure.
  • If the number of points is 100 or fewer, vector points are acceptable.
  • If points heavily overlap, also consider smaller marker size, transparency, hexbin plots, 2D density plots or summary statistics instead of drawing every point as a separate vector marker.
Scatter point count Recommended treatment
<= 100 points Vector points are acceptable.
> 100 points Rasterize the point layer at 300 dpi or higher; keep the rest of the figure vector.

7. Multi-Panel Figures

  • Assemble multi-panel figures inside Python or R when possible.
  • Export the complete final figure as one PDF file.
  • Keep panel labels, axes, lines, arrows, boxes and scale bars as vector text or vector graphics.
  • If a panel contains a dense scatter plot, rasterize only that point layer.
  • Try to keep the final PDF under 50 MB.

8. Python/Matplotlib Template

Use this pattern for Python plots. Save only as PDF. For scatter plots with more than 100 points, set rasterized=True on the point layer. 

import matplotlib as mpl
import matplotlib.pyplot as plt
import numpy as np

# Choose target width in mm
column_width_mm = 85       # Default 1-column width for non-Nature journals
# column_width_mm = 88     # Nature Research 1-column
# column_width_mm = 175    # Default 2-column width for non-Nature journals
# column_width_mm = 180    # Nature Research 2-column

figure_height_mm = 70      # Adjust as needed

# Convert mm to inches
fig_width_in = column_width_mm / 25.4
fig_height_in = figure_height_mm / 25.4

mpl.rcParams.update({
    # Sans-serif font, preferably Helvetica or Arial
    "font.family": "sans-serif",
    "font.sans-serif": ["Helvetica", "Arial", "DejaVu Sans"],

    # Keep text between 5 pt and 7 pt
    "font.size": 6,
    "axes.titlesize": 6,
    "axes.labelsize": 6,
    "xtick.labelsize": 5,
    "ytick.labelsize": 5,
    "legend.fontsize": 5,
    "figure.titlesize": 6,

    # Keep text editable/selectable in PDF
    "pdf.fonttype": 42,

    # Useful saving behaviour
    "savefig.bbox": "tight",
    "savefig.pad_inches": 0.02,

    # Affects rasterized artists and embedded raster images
    "savefig.dpi": 300
})

# Example data
n_points = 500

# Rasterize point layer if there are too many points
rasterize_points = n_points > 100

rng = np.random.default_rng(1)
x = rng.normal(size=n_points)
y = rng.normal(size=n_points)

# Example plot
fig, ax = plt.subplots(
    figsize=(fig_width_in, fig_height_in),
    constrained_layout=True
)

# Scatter points
# If n_points > 100, rasterized=True prevents each dot from becoming a separate vector object in the PDF.
ax.scatter(
    x,
    y,
    s=8,
    alpha=0.7,
    linewidths=0,
    edgecolors="none",
    rasterized=rasterize_points
)

# Optional trend line: keep this vectorized
coefficients = np.polyfit(x, y, 1)
x_sorted = np.sort(x)
y_fit = np.polyval(coefficients, x_sorted)

ax.plot(
    x_sorted,
    y_fit,
    color="black",
    linewidth=0.8,
    rasterized=False
)

ax.set_xlabel("Time")
ax.set_ylabel("Response")
ax.set_title("Example figure")

# Save final figure as PDF only
fig.savefig("figure1.pdf")

Python Notes

  • Use fig.savefig("figure1.pdf").
  • Do not use fig.savefig("figure1.png"), jpg, eps, tiff or other formats for final submission.
  • Set pdf.fonttype = 42 so text remains editable/selectable.
  • Use rasterized=True only on the scatter point layer when n_points > 100.
  • Keep axes, labels, legends, trend lines and annotations vectorized by leaving rasterized=False or not setting it.
  • If using Seaborn, configure Matplotlib after setting the Seaborn theme.
import seaborn as sns

sns.set_theme(style="whitegrid", rc=mpl.rcParams)

9. R/ggplot2 Template

Use this pattern for R plots. Save only as PDF. For scatter plots with more than 100 points, use ggrastr::geom_point_rast() to rasterize the point layer while keeping the rest of the figure vector. 

library(ggplot2)

# Required for rasterizing dense scatter points:
# install.packages("ggrastr")
library(ggrastr)

# Choose target width in mm
column_width_mm <- 85      # Default 1-column width for non-Nature journals
# column_width_mm <- 88    # Nature Research 1-column
# column_width_mm <- 175   # Default 2-column width for non-Nature journals
# column_width_mm <- 180   # Nature Research 2-column

figure_height_mm <- 70     # Adjust as needed

# Convert mm to inches
fig_width_in <- column_width_mm / 25.4
fig_height_in <- figure_height_mm / 25.4

# Example data
n_points <- 500

set.seed(1)
df <- data.frame(
    x = rnorm(n_points),
    y = rnorm(n_points)
)

# Set a compact theme with text between 5 pt and 7 pt
theme_set(
  theme_classic(base_size = 6, base_family = "Arial") +
    theme(
      text = element_text(size = 6, family = "Arial"),
      title = element_text(size = 6),
      plot.title = element_text(size = 6),
      plot.subtitle = element_text(size = 5),
      plot.caption = element_text(size = 5),
      axis.title = element_text(size = 6),
      axis.text = element_text(size = 5),
      legend.title = element_text(size = 6),
      legend.text = element_text(size = 5),
      strip.text = element_text(size = 6),
      panel.grid.minor = element_blank()
    )
)

# Base plot without points
p <- ggplot(df, aes(x = x, y = y)) +
  labs(
    title = "Example figure",
    x = "Time",
    y = "Response"
  )

# Add points
# If n_points > 100, rasterize the point layer.
if (n_points > 100) {
  p <- p +
    geom_point_rast(
      size = 0.5,
      alpha = 0.7,
      dpi = 300
    )
} else {
  p <- p +
    geom_point(
      size = 0.5,
      alpha = 0.7
    )
}

# Optional trend line: keep this vectorized
p <- p +
  geom_smooth(
    method = "lm",
    se = FALSE,
    linewidth = 0.5,
    color = "black"
  )

# Save final figure as PDF only
ggsave(
  filename = "figure1.pdf",
  plot = p,
  width = fig_width_in,
  height = fig_height_in,
  units = "in",
  device = cairo_pdf,
  limitsize = FALSE
)

R Notes

  • Use ggsave(filename = "figure1.pdf", device = cairo_pdf).
  • Do not use postscript(), png(), jpeg(), tiff() or other final output devices.
  • Use Arial or Helvetica if available.
  • If Arial is unavailable, use another sans-serif font.
  • For dense scatter plots, use ggrastr::geom_point_rast() instead of geom_point() when n_points > 100.
  • Keep trend lines, axes, labels and legends vectorized.
  • Check that the PDF text is selectable and not converted to outlines.

10. Final QC Checklist for the Agent

Format

  • Final file is PDF.
  • No EPS, AI, PPT, PNG, JPG, TIFF, BMP, GIF, GIMP or Tex file is produced as the final figure.
  • Text is editable/selectable in the PDF.
  • Lines, axes, labels and legends are vector objects.

Size

  • 1-column width is 85 mm, or 88 mm for Nature Research Journals.
  • 2-column width is 175 mm, or 180 mm for Nature Research Journals.
  • The figure is created at final size, not resized afterwards.

Text

  • All text is sans-serif.
  • Helvetica or Arial is used when available.
  • All text is between 5 pt and 7 pt.

Colour

  • The figure uses RGB colour.
  • No CMYK PDF is generated.

Scatter plots

  • If the scatter plot has more than 100 points, the point layer is rasterized.
  • The PDF does not contain one separate vector object per dot.
  • Axes, labels, legends, trend lines and annotations remain vectorized.
  • Rasterized point layers are created at 300 dpi or higher.
  • The final delivered file is still PDF only.

Effects

  • No drop shadows.
  • No 3D rotation.
  • No bevels.
  • No glow effects.
  • No low-resolution screenshots or pasted raster graphics.

File size

  • The final PDF is preferably under 50 MB.
